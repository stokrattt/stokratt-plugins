Плагіни для Claude Code. Перший з них `korotko`.

## korotko

Output style, з яким Claude відповідає як зайнятий колега: спершу відповідь,
потім тільки те, що треба, щоб діяти. Стиль формує кожну відповідь, хоч про
код, хоч про статтю, лист чи план на вихідні. Працює однаково англійською та
українською і прибирає з кожної мови її власні слова-заповнювачі.

### Два питання, по дві відповіді

Задача з текстом:

> Скороти речення: "У зв'язку з тим, що погода була погана, нами було прийнято
> рішення перенести поїздку."

Стандартний стиль:

> Звісно! Ось коротший варіант: "Через погану погоду ми вирішили перенести
> поїздку." Тут я прибрав громіздкий зворот "у зв'язку з тим, що" і замінив
> пасивне "нами було прийнято рішення" на пряме "ми вирішили", тож речення
> стало чіткішим і виразнішим. Якщо хочеш, можу запропонувати ще кілька
> варіантів!

З `korotko`:

> "Через погану погоду ми перенесли поїздку."

Просив речення, отримав речення. Без екскурсії по правках і без пропозиції
зробити ще.

Задача з кодом:

> Як скасувати останній коміт у git, але лишити зміни?

Стандартний стиль:

> Чудове питання! Скасування комітів часто збиває з пантелику, тож давай
> розберемось. По суті, Git пропонує кілька потужних варіантів, і вибір
> залежить від ситуації. Найпоширеніший підхід це `git reset --soft HEAD~1`,
> який повертає гілку на один коміт назад і зберігає зміни в staged, що
> свідчить про гнучкість дизайну Git. Варто зазначити, що коли ти вже
> запушив, треба бути обережним. Сподіваюсь, це допомогло!

З `korotko`:

> `git reset --soft HEAD~1`. Коміт зникне, зміни лишаться в staged.
>
> Вже запушив? Тоді `git revert HEAD`, він не переписує історію, яку інші вже
> стягнули.

Ті самі факти, втричі менше слів, і команда в першому рядку.

### Що прибирається

| Зворот | Було | Стало |
| --- | --- | --- |
| Розгін | "Давай розберемось. Автор книжки стверджує, що..." | "Автор книжки стверджує, що..." |
| Штучний контраст | "Це не просто дієта, а спосіб життя." | "Дієта обмежує цукор до 25 г на день." |
| Дієприслівниковий причеп | "Продажі зросли на 12%, що свідчить про успіх кампанії." | "Продажі зросли на 12%." |
| Канцелярит | "Комісія здійснює розгляд заяв." | "Комісія розглядає заяви." |
| Роздута значущість | "Знаковий момент, що відкриває нові можливості." | Закінчити на останньому факті. |
| Здогадка як факт | "Тут автор іронізує." | "З тексту не видно, чи це іронія." |
| Залишок чату | "Сподіваюсь, це допомогло!" | Нічого. |

Ті самі звороти описані з англійськими прикладами: "not just X, but Y",
"let's break it down", "highlighting the importance" та інші.

### Що змінюється

- Обсяг: перше речення це відповідь. Відповідь вкладається в 40 рядків, якщо
  ти не просив звіт, план, пояснення чи ревью. Без альтернатив, про які не
  питали: одна рекомендація замість огляду.
- Форма: таблиця тільки для порівняння 3+ об'єктів за 2+ ознаками. Список
  тільки для незалежних пунктів. Заголовки тільки коли секцій 3+. Решта
  проза. Не більше трьох виділень жирним на відповідь.
- Слова: без заповнювачів на кшталт "ключовий", "потужний", "забезпечує" чи
  "crucial", "leverage", "delve". Без довгих тире і кривих лапок. Активний
  стан, одна дія на речення, один термін для однієї речі.
- Правки: просиш виправити одне речення, і змінюється тільки воно. Три правки
  підряд "досі не те", у коді чи в тексті, і Claude зупиняється, називає, що
  міг зрозуміти не так, і ставить одне питання.
- Кінцівка: без "отже", без "сподіваюсь, це допомогло", без рядка, що
  повторює відповідь. Останнє речення це факт або питання.

### Коли стиль відступає

Ліміти вимикаються, коли ти просиш пояснення, повну версію, звіт чи ревью.
Текст помилки, вивід тестів, попередження безпеки і підтвердження незворотних
дій завжди йдуть повністю. А коли коротка відповідь була б здогадкою, Claude
ставить одне питання.

### Чому output style, а не скіл

Скіл завантажується, коли Claude вирішить, що він доречний, або коли ти його
викличеш. Output style стоїть у системному промпті, тож формує кожну
відповідь від першого повідомлення до останнього. `korotko` вмикає
`keep-coding-instructions: true`: Claude Code лишає свої інструкції для роботи
з кодом, а змінюється тільки манера відповіді.

## Встановлення

```bash
claude plugin marketplace add stokrattt/stokratt-plugins
claude plugin install korotko@stokratt-plugins
```

Потім у Claude Code запусти `/output-style` і вибери `korotko:korotko`. Або
пропиши у файлі налаштувань:

```json
{ "outputStyle": "korotko:korotko" }
```

| Що | Команда |
| --- | --- |
| Вимкнути | `/output-style`, потім `Default` |
| Оновити | `claude plugin update korotko@stokratt-plugins` |
| Видалити | `claude plugin uninstall korotko@stokratt-plugins` |
| Спробувати без встановлення | `claude --plugin-dir ./plugins/korotko --settings '{"outputStyle":"korotko:korotko"}'` |

## Під себе

Усі правила лежать в одному файлі:
[`plugins/korotko/output-styles/korotko.md`](plugins/korotko/output-styles/korotko.md).
Зроби форк, відредагуй файл і запусти перевірки:

```bash
python3 -m unittest discover tests
```

Тести перевіряють маніфести і frontmatter стилю. Ще вони стежать, щоб у
файлах не було довгих тире, кривих лапок, особистих шляхів і email.

## Структура

```
.claude-plugin/marketplace.json     маркетплейс і список плагінів
plugins/korotko/

  output-styles/korotko.md          правила
tests/test_plugins.py               статичні перевірки
AGENTS.md                           інструкції для агентів
```
